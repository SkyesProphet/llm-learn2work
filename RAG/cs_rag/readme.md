# 网络安全知识问答 RAG 系统设计

## 项目概述
这是一个基于网络安全知识的RAG（检索增强生成）问答系统。系统通过结构化的网络安全知识文档构建向量仓库，并采用混合检索技术提升检索效果。大模型的回答基于本地知识库内容，确保专业性和准确性。

### 核心特性
- **混合检索**：结合FAISS向量检索和BM25关键词检索，使用RRF算法进行结果重排
- **智能查询理解**：支持查询重写和路由，提升用户查询的匹配度
- **结构化数据处理**：使用Markdown标题分割器对文档进行结构化分块
- **元数据驱动**：提取来源文件、章节标题、块编号等元数据，支持精细化过滤
- **阿里百炼API集成**：兼容OpenAI接口规范，使用qwen3.5-plus等先进模型

## 各模块功能实现说明

### 基础模块
1. `config.py` - 配置管理中心
   
   **功能模块**
   - **路径配置**：定义项目根目录、知识库目录、向量索引目录、元数据目录的绝对路径
   - **模型配置**：
     - Embedding模型：`sentence-transformers`
     - LLM提供商：阿里百炼平台
     - 推荐模型：`qwen3.5-plus` (平衡效果、速度和成本)
     - API Key管理：通过环境变量`DASHSCOPE_API_KEY`安全存储
     - Base URL：`https://dashscope.aliyuncs.com/compatible-mode/v1`
   - **RAG参数**：
     - 文本分块大小：512 tokens
     - 重叠长度：64 tokens
     - 检索数量：5个文档
     - 相似度阈值：0.7
   - **提示词模板**：定义系统提示词，控制LLM回答风格和边界
   - **日志配置**：设置日志级别(Info)和输出格式

2. `main.py` - 主程序入口

   **功能模块**
   - **系统初始化**：加载配置，初始化各核心模块
   - **索引检查**：启动时检查向量索引是否存在，必要时自动构建
   - **问答接口**：提供 `query()` 方法供外部调用
   - **交互模式**：提供命令行交互式问答界面
   - **异常处理**：捕获并处理运行时的各类异常
   - **热重载**：支持知识库更新后自动重建索引

3. `requirements.txt` - 依赖管理

   **功能模块**
   - **向量数据库**：`chromadb` - 存储和检索向量
   - **Embedding模型**：`sentence-transformers` - 文本向量化
   - **LLM调用**：`openai` SDK - 调用阿里百炼API
   - **文档处理**：`pypdf`, `markdown` - 解析各类文档
   - **工具库**：`numpy`, `tqdm`, `rank_bm25` - 数值计算和检索优化
   - **日志**：`loguru` - 结构化日志记录

### rag_modules/ 核心模块
1. `rag_modules/__init__.py` - 模块包初始化

2. `rag_modules/data_preparation.py` - 数据准备模块

   **功能说明**
   - **文档加载**：读取 `.md`、`.txt`、`.pdf` 等格式的文档
   - **文本清洗**：移除多余空白、特殊字符、无关内容
   - **文本分块**：按标题/段落/固定长度切分文本
     - 对于Markdown文件，使用`MarkdownHeaderTextSplitter`进行结构化分割
     - 生成唯一块编号作为标识符
     - 支持可配置的分块策略
   - **元数据提取**：
     - 记录来源文件、章节标题、块编号等信息
     - 将元数据导出到`metadata/`目录下的JSON文件
     - 支持元数据验证和完整性检查
   - **过滤器设计**：
     - 按分类、主题、敏感级别等维度设计过滤器
     - 为后续智能检索、分级检索做准备
   - **数据验证**：检查分块质量，过滤空块或过短块
   - **增量更新**：支持新文档的增量处理

3. `rag_modules/index_construction.py` - 索引构建模块

   **功能说明**
   - **初始化**：初始化索引构建模块和嵌入模型
   - **向量索引构建**：
     - 使用FAISS构建向量索引
     - 支持HNSW索引类型以提升检索效率
   - **相似度搜索**：实现基于余弦相似度的搜索
   - **索引管理**：
     - 删除、更新、保存、加载索引
     - 向现有索引添加新文档（增量索引）
     - 自动版本控制和备份
   - **统计查询**：提供索引状态和性能指标
   - **索引优化**：定期执行索引压缩和优化

4. `rag_modules/retrieval_optimization.py` - 检索优化模块

   **功能说明**
   - **混合检索**：负责混合检索和过滤
     - 参数：`vectorstore`: FAISS向量存储，`chunks`: 文档块列表
   - **检索器设置**：
     - 初始化向量检索器(FAISS)
     - 初始化关键词检索器(BM25)
   - **混合检索流程**：
     - 并行执行向量检索和BM25检索
     - 使用RRF(Reciprocal Rank Fusion)算法进行结果重排
     - 可配置的权重参数
   - **元数据过滤**：支持基于元数据的条件过滤
   - **上下文格式化**：将检索结果格式化为LLM可读的上下文
   - **知识充分性判断**：基于检索分数和上下文长度判断是否足以回答问题
   - **性能监控**：记录检索延迟和命中率

5. `rag_modules/generation_integration.py` - 生成集成模块

   **功能说明**
   - **初始化**：初始化生成集成模块
   - **LLM集成**：
     - 初始化大语言模型（接入阿里百炼API）
     - 实现连接池和请求重试机制
     - 支持流式响应
   - **回答生成**：
     - 生成基础回答：简洁直接的答案
     - 构建分步骤回答：详细、格式化的逐步解答
     - 支持多轮对话上下文管理
   - **智能查询重写**：
     - 使用大模型判断是否需要重写查询
     - 包含详细的提示词工程
     - 返回重写后的查询或原查询
   - **查询路由**：
     - 根据查询类型选择不同的处理方式
     - 路由类型：`list`(列举类), `detail`(详细解释类), `general`(通用类)
     - 动态调整处理策略
   - **上下文构建**：
     - 构建上下文字符串
     - 实现上下文长度限制和优先级排序
   - **输出方式**：
     - 基础回答方式
     - 详细步骤回答（支持流式输出）
     - JSON格式输出选项

### knowledge_base/ 知识库目录

**文档规范**：
- 使用标准Markdown格式
- 统一的标题层级结构
- 包含元数据标记（如分类、创建时间等）
- 定期审核和更新机制

### vector_index/ 向量索引目录

**管理策略**：
- 自动生成和版本控制
- 定期备份
- 增量更新支持
- 索引健康检查

### metadata/ 元数据存储目录

**存储格式**：
- JSON格式存储
- 包含文档ID、来源、创建时间、修改时间等信息
- 支持快速查询和关联分析
